# 2D Items (flat2d)

Fabric-Mod fuer Minecraft 1.21.11: zeigt Items flach (2D) wie in aelteren Versionen.
Einstellungen nur ueber das ModMenu (Mods -> 2D Items -> Zahnrad), keine Taste.

## Bauen
1. Aus dem ItemSize-Repo kopieren: `gradlew`, `gradlew.bat`, Ordner `gradle/`
   (und bei Bedarf die Versionen aus dessen `gradle.properties`).
2. Auf GitHub pushen -> Tab "Actions" -> Artefakt `flat2d` -> Jar herunterladen.
3. Jar in `.minecraft/mods`.
